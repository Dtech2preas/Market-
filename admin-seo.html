SEO Management

Manage OpenGraph previews and static SEO files for active businesses.

How to update SEO

To allow WhatsApp and social media to see rich link previews (images and titles), you must manually propagate the SEO.

  1. Click "Copy HTML" or "Download" for a business below.
  2. Upload it to the GitHub repository in the /profile folder.
  3. Name the file exactly as the shown filename (e.g., slug.html).
  4. Click "Mark as Propagated" so the user is notified on their dashboard.
